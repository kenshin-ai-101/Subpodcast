# Subpodcast · 声译 — 产品需求（MVP）

> 让中文用户无障碍地听、看海外播客与 YouTube 节目，并能和每一集对话。

## 目标用户
- 想追海外科技/商业/AI 播客，但英语听力跟不上或时间有限的中文用户。
- 也追小宇宙等中文播客，希望有文字稿、能提问。

## 核心场景（MVP）
1. **订阅**：搜索节目（Apple Podcasts）、粘贴链接或 RSS、导入订阅（浏览器 YouTube / OPML / Takeout 等）。
2. **听或看**：视频 / 仅音频切换；YouTube 内嵌叠字幕；倍速、跳转、记住进度；收藏 / 离线下载 / YouTube 外开；有频道时显示订阅条。
3. **双语字幕**：官方字幕优先；没有则本机识别（Qwen3 / Whisper，音频不出本机）或云端（明示上传）；谷歌或自有模型翻译；`C` 切换双语/中文/原文；播放器默认叠字幕。
4. **右栏四 Tab**：字幕 · 精读（`episodes.deep` + blob `deep-read`）· 导读 · 问答。
5. **AI 导读**：右栏「导读」Tab（`SummaryPane`）；先查共享导读，再本机生成；blob `summary` / `summary-from`；成稿可豆包朗读、可匿名上传共享库。
6. **AI 问答**：基于整集文稿提问，回答带可点击时间戳；快捷提示词、模型内切、会话与历史持久化。
7. **设置**（字幕 / AI / 通用 / 学英语；不做「关于」）：阅读与本机/云端识别、模型 Key（钥匙串）、界面/网络/快捷键/存储；英语学习模式开关与水平。
8. **英语学习模式**（默认关，只对英文节目）：字幕标超水平词、点词查 ECDICT、句内 AI 释义、原声剪辑、生词本 + FSRS 复习、跟读/听写、本期生词批量收藏、导出 Anki/CSV。

## 成功标准
- 订阅 YouTube 频道后，打开有官方字幕的视频，约 10 秒内出现原文，翻译陆续跟上。
- 问「他们怎么看 AGI？」能返回带时间戳的中文回答，点击可跳转。

## 文案原则
- 按钮说结果：「生成字幕」「翻译成中文」
- 云端选项下说明：「音频会上传，按量计费」
- 用户未选择时，永不把音频发到云端
