# SubCast · 声渡 — 产品需求（MVP）

> 让中文用户无障碍地听、看海外播客与 YouTube 节目，并能和每一集对话。

## 目标用户
- 想追海外科技/商业/AI 播客，但英语听力跟不上或时间有限的中文用户。
- 也追小宇宙等中文播客，希望有文字稿、能检索、能提问。

## 核心场景
1. **订阅**：粘贴 YouTube 频道 / Apple Podcasts 链接 / 小宇宙节目链接 / 任意 RSS，或搜索播客名，一键订阅；自动拉取新单集。
2. **听或看**：播客音频播放；YouTube 在 App 内看视频画面。倍速、跳 15 秒、记住进度。
3. **双语字幕**：
   - 优先**官方字幕**：YouTube 人工字幕 > YouTube 自动字幕；RSS 的 `<podcast:transcript>`（VTT/SRT/JSON）。
   - 没有则**本机转写**（whisper.cpp，音频不出本机），或用户选定的云端识别（豆包 / 硅基流动 Qwen3-ASR / OpenAI 兼容）。
   - AI 翻译为中文，原文/中文/双语三种显示；当前句高亮随播放滚动；点句子跳转。
4. **AI 问答与总结**：基于整集文稿提问，回答带可点击时间戳；一键中文摘要 + 章节要点。
5. **设置**：模型服务（用户自带 Key，存系统钥匙串）、网络代理（国内访问 YouTube 必需）、转写模型下载与管理。

## 明确的边界（MVP 不做）
- Apple Podcasts 自己生成的文字稿仅在其 App 内可见，无法获取 → 走 `podcast:transcript` 或转写。
- 小宇宙无公开文字稿接口 → 一律转写。
- 账号体系、云同步、移动端（第二版）。
- 整集文稿导出到文件 / Obsidian 深度集成（第二版）。最小版已支持：字幕栏「⋯」复制整集 Markdown 到剪贴板（双语 / 原文 / 中文）。
- Windows / Linux 安装包由 CI 构建；本机只验证 macOS。

## 成功标准
- 订阅一个 YouTube 频道，打开任一视频 10 秒内出现英文字幕，1 分钟内出现中文翻译的前几屏。
- 一集 60 分钟无字幕英文播客，在 Apple 芯片上本机转写 < 5 分钟。
- 问「他们怎么看 AGI 时间线？」能返回带 3 个以上时间戳的中文回答，点击可跳转。

## 用户可见文案原则（沿用乔木剪藏）
- 按钮说结果：「生成字幕」「翻译成中文」，不说「开始 ASR 任务」。
- 数据去向在选项下说一次：「云端 · 音频会上传，按量计费」。
- 永不在用户未选择时把音频发到云端。
