# Subpodcast · 声译 — 产品需求文档（v1.2）

> 让中文用户无障碍地听、看海外播客与 YouTube 节目，并完成「听懂 → 理解 → 复习 → 传播」的桌面端闭环。

## 1. 目标用户与定位

- **核心用户**：追海外科技、商业、AI 与人文播客/YouTube 访谈，但英语听力吃力或希望高效提炼内容的中文听众。
- **延伸用户**：收听小宇宙等中文长播客、需要文字稿检索、AI 导读问答或英语精听精学的用户。
- **形态**：本地优先（Local-First）跨平台桌面应用（当前重点打磨 macOS 11+）。

## 2. 功能需求全景

### 2.1 订阅、发现与媒体库
- 搜索（Apple Podcasts + 精选目录）、粘贴链接/RSS、导入（浏览器 YouTube 订阅 / OPML / Takeout）。
- 首页（继续收听、接下来听、为你推荐）、发现页（分类筛选与精选网格）、独立「最近与收藏」视图、节目详情（月份热力筛选与搜索）、收听统计与 AI 听众画像。
- 路由与播放正交（`view ⊥ current`）：浏览其他节目不打断当前播放，离页由迷你播放器统一控播。

### 2.2 音视频双形态播放与离线容灾
- 支持 YouTube 视频 / 仅音频无缝切换、全屏 Theater 舞台、视频双语叠字幕（无底描边 / 柔底卡片）。
- 离线下载单集音频，断网自动切仅音频并优先使用本地文件；本地文件异常自动回退远端。
- 支持倍速、快进/快退、进度持久化、连播队列、系统媒体键（`MediaSession`）与 19 项可自定义快捷键（`⌘/` 速查）。

### 2.3 双语字幕瀑布、识别与翻译
- **字幕瀑布**：本地库 → 官方字幕（YouTube 选轨 / RSS `podcast:transcript` / Podscribe / 乔木）→ 共享字幕库 → 空态引导用户手动触发本机识别（Qwen3-ASR / Whisper）或云端识别。
- **翻译**：支持播放头优先自适应并发机翻（谷歌 / 自有 LLM）；LLM 翻译支持「快速（单阶段）」与「精翻（二阶段上下文术语润色）」。
- **字幕工具**：`C` 切换双语/中文/原文、文稿内关键词搜索、自动跟随锁定、失败一键重试、多格式导出（SRT / VTT / ASS / LRC / TXT / Markdown）。

### 2.4 右栏四 Tab 深度理解与朗读
- **字幕**（含「高光」子模式）· **精读**（乔木改写长文，仅真有改写的单集显示）· **导读**（先查共享导读再本机流式生成）· **问答**（整集带时间戳上下文、快捷提示词、会话归档、模型内切；导读与问答支持并行流式且停止即时取消后端任务）。
- **多引擎朗读**：支持系统增强语音、Edge Read Aloud、本机离线神经语音（Melo / Kokoro）与云端语音服务，统一响应全局音量与语速。

### 2.5 英语学习模式（默认关，仅对英文节目生效）
- 离线 ECDICT 词典、按目标水平（四级/六级/考研/雅思）标词、支持标记「已认识」不再高亮。
- 点词弹出词卡（释义、句内 AI 释义、原声句级剪辑、加入生词本 / 标为认识）。
- 生词本（FSRS 遗忘曲线复习、回想/拼写模式、跟读/听写、本期生词批量收藏、学习热力统计、Anki `.apkg` / CSV 导出）。

### 2.6 高光短视频工作室
- 字幕就绪后 AI 分窗抽取金句高光，在文稿与进度条上标示，支持试看、定向意图重抽与多段蒙太奇拼接。
- 宽屏双栏 WYSIWYG 剪辑弹窗（正片裁切/双语字幕样式/标题水印、8 款封面模板、多平台传播文案），导出 H.264 + AAC MP4 与封面图。

### 2.7 设置、外观与国际化
- 5 个一级分组：字幕 / AI / 朗读 / 通用 / 学英语（明确不做「关于」页）。
- 外观支持「跟随系统 / 浅色 / 深色」手动切换；macOS 采用 `TitleBarStyle::Overlay` 一体式标题栏。
- 界面语言支持「跟随系统 / 简体中文 / 繁體中文 / English」完整三语切换。

## 3. 隐私与安全基线

- **音频不出本机原则**：用户未显式选择云端 ASR 服务前，绝不向云端发送音频。
- **匿名共享默认关闭**：`shareTranscripts` 默认 `false`；首次识别后轻量询问用户意愿；含鉴权参数或内网私有源永不上传。
- **最小权限边界**：启用 CSP；远端 HTML 经 DOMPurify 清洗；外部链接限 `http(s)`；IPC 读写与打开操作执行白名单路径/扩展名校验；API Key 仅发往已持久化保存的服务域名。

## 4. 明确不做（当前版本边界）

- 设置「关于」页、金句海报（已由高光视频封面取代）、账号与云同步、移动端、OTA 界面热更新。

## 5. 非功能性指标与验收标准

| 维度 | 验收标准 |
|---|---|
| **首屏与字幕** | 打开带官方字幕的 YouTube 单集，10 秒内呈现原文，翻译按播放头优先陆续跟上。 |
| **长播客性能** | 3 小时 / 3,000+ 句字幕单集连续播放与快速滚动无主线程掉帧（虚拟滚动 + 零整页 4Hz 重渲染）。 |
| **窗口适配** | 在最小窗口 `960×640` 及常规 `1280×840` / `1440×900` 下，单集播控、右栏工具条与剪视频工作室均无裁切溢出。 |
| **对比度与无障碍** | 浅色/深色模式下文本与交互按钮满足 WCAG AA（≥4.5:1），全站支持键盘焦点环与 `Esc` 关闭弹窗。 |
| **工程门禁** | `tsc --noEmit`、`vitest run`、`biome check`、`npm run i18n -- --strict`、`cargo test --lib` 全部通过。 |
