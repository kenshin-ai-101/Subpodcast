# Subpodcast · 声译 — 产品需求（MVP）

> 让中文用户无障碍地听、看海外播客与 YouTube 节目，并能和每一集对话。

## 目标用户
- 想追海外科技/商业/AI 播客，但英语听力跟不上或时间有限的中文用户。
- 也追小宇宙等中文播客，希望有文字稿、能提问。

## 核心场景（MVP）
1. **订阅**：搜索节目（Apple Podcasts）、粘贴链接或 RSS、导入订阅（浏览器 YouTube / OPML / Takeout 等）。
2. **听或看**：音频播放；YouTube 内嵌；倍速、跳转、记住进度。
3. **双语字幕**：官方字幕优先；没有则云端识别（明示上传）；谷歌或自有模型翻译。
4. **AI 问答**：基于整集文稿提问，回答带可点击时间戳。
5. **设置**（字幕 / AI / 通用；不做「关于」）：阅读与识别、模型 Key（钥匙串）、界面/网络/快捷键/存储；本机 ASR 与本机 Agent 检测留二期。

## 明确不做（本期）
- 本机 ASR（Qwen3 / Whisper）
- 设置「关于」、共享字幕网络、乔木精读、金句海报、账号云同步、移动端、OTA 热更新

## 成功标准
- 订阅 YouTube 频道后，打开有官方字幕的视频，约 10 秒内出现原文，翻译陆续跟上。
- 问「他们怎么看 AGI？」能返回带时间戳的中文回答，点击可跳转。

## 文案原则
- 按钮说结果：「生成字幕」「翻译成中文」
- 云端选项下说明：「音频会上传，按量计费」
- 用户未选择时，永不把音频发到云端
